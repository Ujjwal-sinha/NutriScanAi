🔬 NutriScanAI

End-to-end nutritional deficiency and retinal analysis platform with fine-tuned models, multi-agent reasoning, explainability, and secure reporting.

📋 System Overview

NutriScanAI delivers a cohesive medical imaging pipeline that blends Streamlit UI, preprocessing, fine-tuned CNN/MLP/BLIP models, GROQ-powered agents, and explainability to classify six nutrition-related conditions and provide actionable clinical insights.

🛠️ Technology Stack

🖥️ Frontend

  • Streamlit UI
  • Mermaid for diagrams
  • PIL/Pillow for image handling
  • HTML/CSS modern layout

⚙️ Backend

  • Python
  • PyTorch + Torchvision
  • OpenCV
  • NumPy & Pandas

🤖 AI/ML

  • Fine-tuned CNN (MobileNet V2)
  • Fine-tuned MLP
  • Fine-tuned BLIP
  • LangChain + GROQ LLM

📊 Data & Reports

  • FPDF for PDF generation
  • Seaborn/Matplotlib for plots
  • Streamlit cache + temp storage
  • CSV ingestion for cholesterol data

🔬 Explainable AI

  • LIME & SHAP
  • Grad-CAM
  • Integrated Gradients
  • Attention-driven captions
