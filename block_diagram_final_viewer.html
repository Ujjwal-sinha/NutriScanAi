🔬 Detailed CNN Architecture Specifications

PatternNet CNN - Texture & Pattern Analysis

  • Input: 224x224x3 RGB images
  • Layer 1: Conv2D (7x7 kernel, 64 filters, stride 2) → BatchNorm → ReLU → MaxPool (3x3, stride 2)
  • Layer 2: Conv2D (5x5 kernel, 128 filters, stride 1) → BatchNorm → ReLU → MaxPool (2x2, stride 2)
  • Layer 3: Double Conv2D (3x3 kernel, 256 filters each, padding same) → BatchNorm → ReLU → MaxPool (2x2, stride 2)
  • Layer 4: Double Conv2D (3x3 kernel, 512 filters each, padding same) → BatchNorm → ReLU → Dropout (0.3) → GlobalAvgPool
  • Output: Dense (512 units) → ReLU → Dropout (0.5) → 512-dimensional feature vector
  • Specialization: Optimized for detecting fine-grained textures, repetitive patterns, and micro-structural features

ChromaNet CNN - Color & Intensity Analysis

  • Input: 224x224x3 RGB images
  • Layer 1: Conv2D (5x5 kernel, 96 filters, stride 1) → BatchNorm → ReLU → MaxPool (3x3, stride 2)
  • Layer 2: Double Conv2D (3x3 kernel, 192 filters each, padding same) → BatchNorm → ReLU → MaxPool (2x2, stride 2)
  • Layer 3: Double Conv2D (3x3 kernel, 384 filters each, padding same) → BatchNorm → ReLU → MaxPool (2x2, stride 2)
  • Layer 4: Double Conv2D (3x3 kernel, 512 filters each, padding same) → BatchNorm → ReLU → Dropout (0.4) → GlobalAvgPool
  • Output: Dense (512 units) → ReLU → Dropout (0.5) → 512-dimensional feature vector
  • Specialization: Designed for analyzing color distributions, intensity variations, and spectral characteristics

StructNet CNN - Spatial & Structural Analysis

  • Input: 224x224x3 RGB images
  • Layer 1: Conv2D (11x11 kernel, 64 filters, stride 4) → BatchNorm → ReLU → MaxPool (3x3, stride 2)
  • Layer 2: Conv2D (5x5 kernel, 192 filters, padding same) → BatchNorm → ReLU → MaxPool (3x3, stride 2)
  • Layer 3: Triple Conv2D (3x3 kernel, 384→384→256 filters, padding same) → BatchNorm → ReLU → MaxPool (3x3, stride 2)
  • Layer 4: Double Conv2D (3x3 kernel, 512 filters each, padding same) → BatchNorm → ReLU → Dropout (0.3) → GlobalAvgPool
  • Output: Dense (512 units) → ReLU → Dropout (0.5) → 512-dimensional feature vector
  • Specialization: Focused on capturing spatial relationships, geometric patterns, and structural configurations

🔑 Common Architecture Components

  • Batch Normalization: Applied after every convolutional layer to stabilize training and improve convergence
  • ReLU Activation: Used throughout for non-linear feature extraction and gradient flow
  • MaxPooling: Reduces spatial dimensions while preserving important features
  • Global Average Pooling: Converts feature maps to fixed-size vectors before dense layers
  • Dropout: Regularization technique (0.3-0.5) to prevent overfitting
  • Feature Vector Size: All three CNNs output 512-dimensional feature vectors for fusion

🎯 Unique Architecture Features

  • Specialized Parallel Processing: Three independent encoders (PatternNet, ChromaNet, StructNet) with distinct specializations process input simultaneously for comprehensive multi-dimensional feature extraction
  • Complementary Feature Extraction: Each CNN model (PatternNet, ChromaNet, StructNet) focuses on different aspects of the image, ensuring no critical information is missed
  • Intelligent Fusion: Advanced fusion mechanism combines diverse multi-modal features from all three encoders with attention weighting
  • Agent-Based Analysis: NutriScanAI Medical Agent provides intelligent reasoning and context-aware disease analysis using fused multi-dimensional features
  • Consensus Mechanism: Ensemble approach ensures robust and reliable classification by validating across multiple feature dimensions
  • Comprehensive Output: Multiple app features provide complete user experience with detailed insights
