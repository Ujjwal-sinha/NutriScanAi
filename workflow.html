🩺 Medical Image Analysis System

Research Paper Sequence Diagrams - 4-Phase Workflow Breakdown

Phase 1: Image Processing

Initial phase where the user uploads a medical image, followed by validation and preprocessing. This includes quality checks, eye detection, and image transformation for further analysis.

sequenceDiagram participant User participant StreamApp participant ImageProc participant PreprocessedImage Note over User, PreprocessedImage: Phase 1: Image Processing User->>StreamApp: Upload Medical Image StreamApp->>StreamApp: Process & Validate Image StreamApp->>ImageProc: Send Image ImageProc->>ImageProc: Quality Check ImageProc->>ImageProc: Eye Detection ImageProc->>ImageProc: Image Transformation ImageProc->>PreprocessedImage: Preprocessed Image Note over User, PreprocessedImage: Image preprocessing completed, ready for AI analysis

Phase 2: AI Models & Agents

AI processing phase where preprocessed images are analyzed by fine-tuned models (CNN, MLP, BLIP) to generate classification results and medical descriptions, sent to AI agents.

sequenceDiagram participant PreprocessedImage participant ParallelProcessing participant FineTunedCNN participant FineTunedMLP participant FineTunedBLIP participant AIAgents Note over PreprocessedImage, AIAgents: Phase 2: AI Models & Agents PreprocessedImage->>ParallelProcessing: Send Preprocessed Image ParallelProcessing->>FineTunedCNN: Fine-tuned CNN Classification ParallelProcessing->>FineTunedMLP: Fine-tuned MLP Analysis (Cholesterol Data) ParallelProcessing->>FineTunedBLIP: Fine-tuned BLIP Captioning (Image Description) FineTunedCNN->>AIAgents: Send Results & Descriptions FineTunedMLP->>AIAgents: Send Results & Descriptions FineTunedBLIP->>AIAgents: Send Results & Descriptions Note over PreprocessedImage, AIAgents: AI model analysis completed, results sent to agents

Phase 3: Specialized Medical Analysis

Specialized analysis phase where AI agents perform symptom checking, risk assessment, and medical analysis. This phase provides detailed medical insights and treatment recommendations based on the AI model results.

sequenceDiagram participant AIAgents participant SymptomChecking participant RiskAssessment participant MedicalDatabase participant TreatmentAdvising participant ReturnAnalysisResults Note over AIAgents, ReturnAnalysisResults: Phase 3: Specialized Medical Analysis AIAgents->>SymptomChecking: Request Specialized Analysis SymptomChecking->>MedicalDatabase: Query Medical Knowledge Base MedicalDatabase->>SymptomChecking: Return Medical Data SymptomChecking->>RiskAssessment: Symptom Matching & Analysis RiskAssessment->>TreatmentAdvising: Risk Assessment (e.g., vital levels) TreatmentAdvising->>ReturnAnalysisResults: Treatment Recommendations ReturnAnalysisResults->>AIAgents: Return Analysis Results Note over AIAgents, ReturnAnalysisResults: Specialized medical analysis completed, ready for explainability

Phase 4: Explainability & Report Generation

Final phase involving explainability analysis and report generation. This phase provides visual explanations and generates a comprehensive medical report.
